# shopsmart-website

ShopSmart is a simple e-commerce website where users can browse products, filter by category, and manage their wishlist.

## Features

- Browse products with images and descriptions
- Search products by name
- Filter products by category
- Responsive design for mobile and desktop
- Sticky footer for better user experience

## Technologies Used

- HTML
- Tailwind CSS
- JavaScript (for interactivity)

## Pages

-index.html  - Homepage with product listing
- wishlist.html  - Wishlist page
- about.html  - About page
